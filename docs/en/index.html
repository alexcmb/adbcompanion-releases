Apps

App management

A complete inventory of installed packages, with icons, sizes and filters.

  • APK, APKS (bundles) and XAPK installation with OBB data, by drag and drop
  • Launch, force stop, disable, clear cache or data, uninstall and restore
  • Bulk actions, with critical system packages protected
  • Permission review and management
Files

File transfer

The explorer relies directly on ADB's sync protocol, without going through the shell.

  • Dual pane, workstation ↔ device, drag and drop from the system file manager
  • Tracked, cancellable transfers (throughput, remaining files)
  • Conflict handling: replace, skip or keep both
  • Image and text file preview, root mode across the whole file system
Terminal

Interactive ADB shell

Full terminal emulation: colors, completion, full-screen programs and dynamic resizing.

  • Multiple sessions in tabs, keyboard navigation
  • Root session when the device allows it
  • Built-in macros (battery, system properties, disk space…) and custom ones
Logcat

Real-time system logs

Smooth rendering at any throughput; pausing actually suspends collection.

  • Filtering by level, tag (with exclusions), app or regular expression
  • Automatic tracking of an app's processes
  • Local or on-device purge, plain-text export
Monitor

Performance monitoring

1 to 30 minutes of history, 1 to 5 second sampling.

  • Load and frequency of each CPU core
  • Memory, sensor temperatures, battery (current, voltage)
  • Process manager: sort, search, kill, memory release
Wireless

Wireless ADB

Wi-Fi connectivity with no IP address or port to enter.

  • QR code pairing (Android 11 and later)
  • Six-digit code pairing or direct connection to an address
  • One-click USB → Wi-Fi switchover, automatic reconnection
  • USB and Wi-Fi connections of the same device grouped together
Screen mirror

Screen mirroring and control

ADB Companion deploys and configures scrcpy automatically.

  • Configurable resolution, bit rate, frame rate and codec
  • Device screen off, touch indicators, session recording
  • Wi-Fi-optimized profile, automatic fallback when the video encoder fails
Quick settings

Advanced system settings

Original values are preserved: the "Restore" action returns the device to its initial state.

  • Animation scale, display resolution and density
  • Stay awake while charging, touch indicators
  • Private DNS, dark theme, force dark
Productivity

Designed for daily use

  • Command palette Ctrl + K: keyboard access to every view and action
  • Reboot to system, recovery, bootloader, fastbootd or EDL; screenshots
  • Notification area icon, device connection notifications
  • Automatic ADB (Platform-Tools) deployment, signed updates
  • Light and dark themes, English and French interface
Light theme

Light theme

The theme follows the system preference or can be set in the settings; the transparency effect can be turned off on lower-end machines.

Frequently asked questions

Windows SmartScreen blocks the installation

The installer is not yet signed with a code signing certificate, so SmartScreen flags it as unrecognized. Select "More info", then "Run anyway". Updates, however, are signed and their signature is verified before installation.

macOS blocks the app from opening

The app is not yet notarized by Apple. In the Applications folder, right-click ADB Companion, choose "Open" and confirm. Use the aarch64 file for Apple Silicon Macs (M1 and later), x64 for Intel Macs.

Are ADB or Android Studio required?

No. ADB Companion detects an existing ADB installation (Android SDK, PATH…) or offers to download Google's official Platform-Tools. scrcpy, used for screen mirroring, is deployed the same way.

How do I configure the device?

In Android settings, open "About phone" and tap "Build number" seven times to enable Developer options. Then turn on "USB debugging" (and "Wireless debugging" for Wi-Fi), connect the device and authorize the computer's RSA key fingerprint.

Is root access required?

No. Root access is only used for some advanced features (whole file system access, root terminal session, clearing an app's cache), when the root manager grants it to the shell.

Where is data stored? Is any information transmitted?

On Windows, the installation is portable: settings, logs and downloaded tools are stored in the application's data folder (the installer offers to remove it on uninstall). No data is transmitted: the app only connects to the Internet to check for updates and, on request, to download ADB or scrcpy.

What is an experimental version?

A pre-release published for testing purposes: early access to features, stability not guaranteed. The "Experimental versions" option (Settings → Updates) delivers them automatically.

Linux: the device is not detected over USB

The user needs access rights to Android USB devices: install your distribution's udev rules (android-udev-rules or android-sdk-platform-tools-common, depending on the distribution), add the user to the matching group (plugdev or adbusers), then reconnect the device.
